Relations and Relations on Sets

A relation from set A to set B is a subset of the Cartesian product A × B. When A = B, we say R is a relation on A. Relations provide a way to describe connections between elements.

Definition: Let A be a set. A relation R on A is a subset of A × A.

R ⊆ A × A = {(x, y) : x ∈ A and y ∈ A}
Example
If A = {1, 2, 3, 4}, then R = {(1,2), (2,3), (3,4), (2,2)} is a relation on A. We write 1R2 to mean (1,2) ∈ R.

Matrix Representation of Relations

A relation can be represented as an adjacency matrix or relation matrix. For a relation R on a finite set A = {a₁, a₂, ..., aₙ}, the matrix M_R is an n × n matrix where:

M_R[i,j] = 1 if (aᵢ, aⱼ) ∈ R M_R[i,j] = 0 if (aᵢ, aⱼ) ∉ R

This binary matrix provides an efficient way to:

  • Store and manipulate relations in computer systems
  • Perform operations like composition and transposition
  • Analyze properties of relations
  • Convert between different representations

Properties of Relations

Relations can possess several important properties. A relation R on a set A is:

  • Reflexive: For all a ∈ A, (a, a) ∈ R
  • Irreflexive: For all a ∈ A, (a, a) ∉ R
  • Symmetric: If (a, b) ∈ R, then (b, a) ∈ R
  • Antisymmetric: If (a, b) ∈ R and (b, a) ∈ R, then a = b
  • Asymmetric: If (a, b) ∈ R, then (b, a) ∉ R
  • Transitive: If (a, b) ∈ R and (b, c) ∈ R, then (a, c) ∈ R
Example: Equality
The equality relation "=" on any set is reflexive, symmetric, and transitive. But it is also antisymmetric: if x = y and y = x, then x = y.

Equivalence Relations

A relation R on a set A is an equivalence relation if it is reflexive, symmetric, and transitive.

Equivalence relations partition a set into disjoint subsets called equivalence classes. Two elements are in the same equivalence class if and only if they are related.

Example: Modular Arithmetic
The congruence relation modulo n is an equivalence relation. Two integers a and b are related if a ≡ b (mod n), meaning they have the same remainder when divided by n.

Properties of equivalence relations:

  • Reflexive: Every element is equivalent to itself
  • Symmetric: If a ~ b, then b ~ a
  • Transitive: If a ~ b and b ~ c, then a ~ c
  • Creates equivalence classes: The set is partitioned into disjoint subsets

Partial Orders

A relation R on a set A is a partial order if it is reflexive, antisymmetric, and transitive.

A partially ordered set (poset) allows us to compare some elements but not necessarily all. Unlike total orders, not every pair of elements needs to be comparable.

A total order additionally requires: For all a, b ∈ A, either (a,b) ∈ R or (b,a) ∈ R
Example: Divisibility
The divisibility relation "divides" on positive integers is a partial order. For example: 2 divides 4, 4 divides 8, so 2 divides 8 (transitivity). But 3 and 5 are incomparable.
  • Reflexive: Every element divides itself
  • Antisymmetric: If a divides b and b divides a, then a = b
  • Transitive: If a divides b and b divides c, then a divides c

Graph Representation

Relations can be visualized as directed graphs (digraphs). In this representation:

  • Vertices: Represent elements of the set A
  • Directed Edges: An arrow from a to b represents (a, b) ∈ R
  • Self-loops: An edge from a vertex to itself represents reflexivity
  • Undirected edges: Between a and b represent symmetry

This visual representation makes it easy to:

  • Identify patterns and cycles
  • Visualize reflexive, symmetric, and transitive properties
  • Understand connectivity and reachability
  • Perform graph algorithms for relation analysis

Applications

Relations and their matrix/graph representations have numerous applications:

  • Database Theory: Relations as tables in relational databases
  • Computer Networks: Adjacency matrices for network topology
  • Social Networks: Friendship and follow relations
  • Scheduling: Precedence relations and dependency graphs
  • Formal Languages: State transition relations in automata
  • Data Structures: Graph algorithms and tree structures
  • Logic and Set Theory: Fundamental in mathematical proofs
  • AI and Machine Learning: Knowledge graphs and semantic networks

Key Takeaways

  • Relations are sets of ordered pairs that define connections between elements
  • Matrices provide a compact binary representation for efficient computation
  • Graphs visualize relations and make patterns easier to understand
  • Properties like reflexivity and transitivity classify relations into important types
  • Equivalence relations partition sets into disjoint classes
  • Partial orders define hierarchical structures and partial comparability
  • Understanding these concepts is essential for computer science, mathematics, and logic
